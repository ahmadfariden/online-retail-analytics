# Project Setup Guide

> Referensi untuk Tahap 1 (Project Setup) di `roadmap.md`. Dokumen ini
> mendefinisikan metode baku setup project supaya tidak diulang-ulang di
> setiap roadmap portofolio.

## Bagian 1 — Skeleton Folder & File Stub

- [ ] Struktur folder dibuat (lihat README.md proyek)
- [ ] File stub (README.md, .gitignore, dst.) sudah ada

## Bagian 2 — Koneksi Repository ke Remote (GitHub)

- [ ] `git init`
- [ ] `git remote add origin <url>`
- [ ] Push pertama (initial commit)

*(Isi detail perintah/checklist sesuai kebiasaan setup kamu sendiri --
dokumen ini dirujuk oleh roadmap tapi belum didefinisikan ulang di sana.)*
